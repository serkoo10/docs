# docs

Сайт документации по личным проектам на Docusaurus. Источник страниц — `README.md` и
`docs/` каждого проекта, перечисленного в `projects.json`.

## Как это работает

1. Доки пишутся в репозитории проекта, в `docs/*.md` (и `README.md`).
2. `pnpm sync` копирует их в `docs/<проект>/` этого репозитория и пересобирает главную.
3. Коммит и пуш в `main` — GitHub Actions собирает сайт и выкладывает на Pages.

Локально: `pnpm start` — сайт с живой перезагрузкой, `pnpm build` — сборка в `build/`.

## Задачи

План проекта лежит в `docs/plan.md` его репозитория. Разделы — этапы, пункты
`- [ ] …` — задачи.

`pnpm tasks <проект>`:

- у пункта без ссылки создаёт issue в репозитории проекта и дописывает ссылку в строку;
- у пункта со ссылкой ставит `[x]`, если issue закрыт, и снимает, если открыт заново.

Дальше задача делается как обычно: ветка, коммиты, закрытие issue. После `pnpm tasks`
и `pnpm sync` план на сайте показывает актуальное состояние.

## Новый проект

Добавить запись в `projects.json` (`name`, `description`, `path`, `repo` — если есть на
GitHub), запустить `pnpm sync`.
