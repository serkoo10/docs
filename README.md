# docs

Сайт документации по личным проектам на Docusaurus: https://serkoo10.github.io/docs/.
Источник страниц — `README.md` и `docs/` каждого проекта, перечисленного в `projects.json`.

## Как это работает

Доки пишутся в репозитории проекта, в `docs/*.md` и `README.md`, и коммитятся как обычно.
Дальше всё автоматически: post-commit-хук проекта (ставится командой `pnpm hooks`)
после коммита, затронувшего `docs/` или `README.md`,

1. заводит issues по новым пунктам плана и коммитит ссылки в `docs/plan.md` проекта;
2. копирует доки всех проектов в `docs/<проект>/` этого репозитория и пересобирает главную;
3. коммитит и пушит этот репозиторий — GitHub Actions собирает сайт и выкладывает на Pages.

Хук работает в фоне и не задерживает коммит; его вывод в `.publish.log`.

Вручную то же самое: `pnpm sync` (копирование), `pnpm tasks <проект>` (план → issues),
`pnpm start` (сайт с живой перезагрузкой), `pnpm build`.

## Задачи

План проекта лежит в `docs/plan.md` его репозитория. Разделы — этапы, пункты `- [ ] …` —
задачи. Пункт без ссылки превращается в issue в репозитории проекта, ссылка дописывается в
строку. Пункт со ссылкой получает `[x]`, когда issue закрыт. Дальше задача делается как
обычно: ветка, коммиты, закрытие issue.

## Новый проект

Добавить запись в `projects.json` (`name`, `description`, `path`, `repo` — если есть на
GitHub), запустить `pnpm hooks`. Без `repo` доки публикуются, задачи не заводятся.
