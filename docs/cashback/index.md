# Кэшбэк

Личный агрегатор кэшбэка по банкам РФ. Добавляешь свои банки, отмечаешь категории
кэшбэка на месяц (руками или по скриншоту из приложения банка), и приложение
показывает, где какая категория сейчас выгоднее всего.

Приложение для iOS на Flutter. Бэкенда нет: данные лежат на устройстве, распознавание
скриншота идёт напрямую в Claude API с собственным ключом пользователя.

## Запуск

```
cd app
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter gen-l10n
flutter run
```

Для распознавания скриншотов нужен ключ API Anthropic (console.anthropic.com): он вводится
в настройках приложения и хранится в Keychain.
