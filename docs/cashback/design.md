# Дизайн

Как выглядит приложение и почему. Код темы — `app/lib/core/theme`, здесь решения.

## 1. Принципы

Основа — тема runclub (iOS HIG): сгруппированный фон, плоские карточки с hairline, один
акцент, семантические цвета статусов, табличные цифры. Палитра «Туман» — спокойные
сине-серые нейтрали, выбрана на брейншторме 2026-10-22 (холст «Cashback — направления
дизайна», вариант I «По ставке»). Отличия продиктованы предметом:

- **Цвет на экране принадлежит банкам.** Каждый банк узнаётся по брендовому цвету из
  каталога: аватар в списках и в подписи «банк-лидер». Чтобы он читался, акцент
  приложения почти монохромный (тёмный сине-серый в светлой, светлый в тёмной). Второго
  варианта акцента нет.
- **Главное число — процент.** Ставка набирается крупно: заголовок группы на «Сейчас» —
  `headlineMedium` (800, −1), ставка в строке — `headlineSmall` (700); табличные цифры,
  формат «7 %» и «1,5 %» (без лишних нулей, запятая, неразрывный пробел).
- **Меньше дизайна.** Никаких дублирующих маркеров: нет точки цвета банка рядом со
  ставкой, если рядом уже аватар; ставка не повторяется в каждой строке, если она
  вынесена в заголовок группы.
- **Статусы:** `warning` — у банка нет категорий на месяц; `success` — набор обновлён в
  этом месяце; `neutral` — прошлый месяц; `danger` — удаление и ошибки распознавания.
- Иконки категорий контурные Material; одна и та же иконка у категории везде
  (`CategoryIcon`).
- Пустые списки — `EmptyState` с одним действием. Загрузка документа одна и быстрая,
  скелетонов нет.
- Тактильный отклик: `select` на чипах и сегментах, `success` при сохранении.
- **Стекло — только у плавающих слоёв.** AppBar, панель вкладок и кнопка «+» лежат на
  `GlassSurface`: размытая подложка, почти непрозрачная заливка `surface`, hairline-ободок
  и мягкая тень. Контент уезжает под них (`extendBodyBehindAppBar`, `extendBody`), а его
  отступы берутся из `MediaQuery.padding` через `scrollInsets` из контекста внутри body.
  Карточки, чипы, плашки, группы настроек, листы и диалоги — плоские поверхности `surface`
  с hairline `separator`, радиус `l`. Фон нейтральный, без цветной подложки.

## 2. Навигация

Три вкладки в плавающей стеклянной капсуле внизу: **Сейчас**, **Банки**, **Настройки**.
Выбранная — залитая пилюля `accent` с иконкой `onAccent`, подписью акцентом и сиянием `accent` α0.35 под ней (как в Telegram), остальные `secondaryLabel`. Пилюля одна на панель: при переключении перетекает к новой вкладке за 420 мс, в середине пути вытягивается каплей (`GlassTabIndicator`).
Поверх — экраны по маршрутам:

| Маршрут | Экран |
|---|---|
| `/` | Главный с тремя вкладками |
| `/banks/add` | Добавить банк (каталог + свой банк) |
| `/banks/:id` | Банк: категории по месяцам |
| `/import?bank=<id>` | Импорт скриншота |
| `/settings/key` | Ключ API |

Редактор категории и выбор категории — bottom sheet, не маршрут: это правка одной строки.

## 3. Экраны

### Сейчас (`BestTab`)

Заголовок — текущий месяц («Октябрь 2026»), в действиях кнопка «Из скриншота» (иконка
камеры). Нижняя строка того же стеклянного AppBar — сегмент «По ставке | По алфавиту»
(`BestSortSegments`), выбор хранится в настройках; при пустой сводке ни кнопки, ни сегмента
нет. Тело — категории, у которых есть хоть одна ставка.

«По ставке» — группы по лучшей ставке, по убыванию; ставка стоит один раз в заголовке
группы (`BestRateHeader`), в строках её нет:

```
10 %
┌──────────────────────────────────────────────┐
│ Кафе и рестораны                           › │
│ (●) Сбер · ещё 1 банк                        │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│ Доставка еды                               › │
│ (●) Альфа-Банк                               │
└──────────────────────────────────────────────┘
7 %
…
```

«По алфавиту» — плоский список, «На всё» первой, в строке справа ставка лидера крупно
вместо шеврона.

Строка (`CategoryBestCard`): название категории, под ним аватар банка-лидера (16 px),
его название, торговая точка и число остальных банков одной строкой через « · ».
Иконки категории и точки цвета в строке нет. Нажатие — `CategorySheet`:
все банки с этой категорией по убыванию, у строки аватар банка, название, торговая точка
и лимит мелко, ставка справа; у банка с командой открытия справа значок «открыть», и нажатие по строке запускает команду. Нажатие по банку без команды предлагает её настроить: диалог «Открывать <банк> отсюда?» → «Настроить» → экран банка с открытым листом команды.

Категория «На всё» не разбивается по остальным; в группах по ставке она стоит в своей
группе, по алфавиту — первой.

Над списком — плашка `warning`, если у части банков нет категорий на этот месяц:
«У 2 банков не выбраны категории» → переход на вкладку Банки.

Поле поиска есть всегда («Категория или магазин»). Запрос от двух символов ищет и по
магазинам: по справочнику `assets/merchants.json` (имя и псевдонимы, регистр, ё и знаки не
важны) и по торговой точке в ставках. Найденная по магазину категория остаётся в списке, а в
подписи строки появляется «магазин «Пятёрочка»» (`categoryBestSubtitle`). Если категории нет
в этом месяце, магазин идёт отдельной секцией «Нет в этом месяце»: «Пятёрочка → Супермаркеты» и
строка с лучшей ставкой «На всё» («Лучшее «На всё»: 1,5 % · Т-Банк») или «Кэшбэка на эту
категорию нет». Под результатами подпись: категорию определяет банк по MCC, это подсказка, а
не гарантия.

Пустых состояния два, по `BestTabState`: без банков — «Пока нечего сравнивать»,
действие «Добавить банк»; банки есть, но категорий на месяц ни у кого нет — «Категории
на октябрь не отмечены», действие «Из скриншота».

### Банки (`BanksTab`)

Список карточек банков в порядке добавления. Карточка: аватар (логотип из `assets/banks/`
в круге, а без логотипа круг брендового цвета с первой буквой), название, программа
лояльности мелко; справа чип состояния на текущий
месяц: «5 категорий» (`success`) или «Нет категорий» (`warning`), плоский чип. Стеклянная
круглая кнопка «+» (`GlassFab`) над панелью вкладок → добавить банк. Свайп карточки влево, как в
Telegram: карточка сдвигается и останавливается, справа красная пилюля «Удалить» с корзиной
(`SwipeReveal` + `BankDeletePill`); нажатие — подтверждение «Удалить банк», вместе с банком
удаляются его категории за все месяцы. Нажатие по открытой карточке или свайп обратно закрывает.

### Банк (`BankScreen`)

AppBar: название, значок «открыть приложение банка» (только если задана команда), меню с
«Команда для открытия» (лист с именем команды из «Команд» и кнопкой «Создать команду», открывающей их редактор; маршрут `/banks/:id?shortcut=1` открывает экран сразу с этим листом) и «Удалить банк» (с
подтверждением). Нижняя строка того же стеклянного AppBar — переключатель
месяца: ‹ Октябрь 2026 ›. Тело — список категорий месяца (`OfferTile`: иконка, название,
торговая точка и лимит второй строкой, ставка справа); нажатие открывает редактор.
Внизу две кнопки: «Из скриншота» (filled) и «Добавить категорию» (outlined). Если месяц
пуст, а предыдущий заполнен, в пустом состоянии действие «Повторить <прошлый месяц>».

### Добавить банк (`AddBankScreen`)

Поиск по названию и псевдонимам. Список каталога с аватарами; уже добавленные банки
серые с галочкой и не нажимаются. В конце списка и в пустой выдаче — «Свой банк»:
лист с полем названия и выбором цвета из восьми пресетов.

### Редактор категории (`OfferEditSheet`)

Лист: выбор категории (поле, по нажатию — лист со списком категорий и поиском), ставка
(числовое поле, допускается дробь), торговая точка (необязательно), лимит в месяц в рублях
(необязательно). «Сохранить» и, для существующей строки, «Удалить» красным.

### Импорт скриншота (`ImportScreen`)

Экран живёт состоянием `ImportState`:

- `recognizing` — превью скриншота, поверх спиннер и «Распознаём…». Отмена — назад.
- `review` — сверху выбор банка (чип с аватаром, по нажатию лист со своими банками;
  если подобранного банка нет среди своих, предлагается добавить его из каталога), затем
  месяц, затем список распознанных категорий тем же `OfferTile` с правкой и удалением.
  Внизу «Сохранить». Если у банка на этот месяц уже есть категории, под кнопкой
  предупреждение «Заменит 4 категории за октябрь».
  После сохранения стек сворачивается до главного: набор текущего месяца ведёт на вкладку
  «Сейчас», набор другого месяца — на экран банка сразу на этом месяце
  (`/banks/:id?month=yyyy-MM`), «назад» оттуда ведёт домой.
- `failed` — текст ошибки по её типу (нет ключа → «Задайте ключ API в настройках» и
  кнопка туда; отказ модели; сеть; лимит) и «Повторить».

Вход в импорт без ключа API сразу открывает диалог с переходом в настройки.

#### Режим «Это выбор категорий» (SwiftUI-версия)

Для скриншота экрана выбора категорий в приложении банка. Переключатель над списком;
во включённом режиме у каждой строки отметка и справа выигрыш «+≈ 420 ₽», под
переключателем «Можно выбрать: N» (Stepper; по умолчанию то, что банк запомнил, иначе 3),
под списком «Итого ≈ 1 240 ₽ в месяц». Лучшие N строк отмечены заранее, отметки можно менять.
Без указанных трат вместо рублей строка-ссылка «Укажите траты, чтобы подсказка считала
рубли» и ничего не отмечено. Сохраняются только отмеченные строки; сохранить без отметок нельзя.

### Траты в месяц (SwiftUI-версия)

Настройки → «Траты в месяц»: список категорий (кроме «На всё») с иконкой и полем рублей
(цифровая клавиатура); пустое поле — категория не учитывается. Во Flutter-версии экрана нет.

### Настройки (`SettingsTab`)

Сгруппированные секции:

- **Распознавание**: «Ключ API» — «Задан ••••a1b2» или «Не задан» → `/settings/key`:
  поле ключа, кнопка «Вставить», ссылка на console.anthropic.com, пояснение, что ключ
  хранится в Keychain и уходит только в Anthropic.
- **Напоминание**: тумблер «Напоминать обновить категории»; строка «День месяца» (1–5)
  появляется только при включённом тумблере.
- **Оформление**: сегмент Системная / Светлая / Тёмная.
- **О приложении**: версия, «Данные хранятся только на этом устройстве».

## 4. Токены

Палитра «Туман»: сине-серые нейтрали, приглушённые статусы. Светлый фон намеренно холоднее и темнее белых карточек, чтобы они не сливались. Значения в `AppPalette`:

| Токен | Светлая | Тёмная |
|---|---|---|
| background | `#E6EBF1` | `#0B0E12` |
| surface | `#FFFFFF` | `#1B2129` |
| fill | `#DAE1EA` | `#2A3340` |
| fillStrong | `#CBD7E4` | `#37424F` |
| label | `#141A22` | `#ECF0F5` |
| secondaryLabel | `#5B6878` | `#9EABBA` |
| tertiaryLabel | `#8A97A6` | `#6E7A88` |
| separator | `#C6CFD9` | `#2A3340` |
| success | `#2F7A4D` | `#6CC98F` |
| info | `#3B5B7A` | `#8FB4D9` |
| warning | `#9A6700` | `#E0B458` |
| danger | `#FF3B30` | `#FF453A` |
| accent / onAccent | `#1C2F44` / `#FFFFFF` | `#DEE8F4` / `#0B0E12` |

Контейнер статуса и `accentContainer` — цвет с альфой 0.15. Отступы `AppSpacing`
4/8/16/24/32, радиусы `AppRadius` 8/12/16/24, кнопки высотой 50. Карточка и поле ввода —
`surface` с hairline `separator` 0.5 px, радиус `l`.

Стекло плавающих слоёв (`AppGlass`, расширение темы):

| Токен | Светлая | Тёмная |
|---|---|---|
| fill | surface с оттенком accent α0.06, всё α0.55 | surface α0.8 |
| rim | label α0.16, 0.5 px | белый α0.12, 0.5 px |
| highlight (фаска сверху до 42 %) | белый α0.9 → 0 | белый α0.1 → 0 |
| shadow (панель вкладок, «+») | label α0.2 | чёрный α0.5 |
| blurSigma / saturation | 16 / 1.5 | 16 / 1.5 |

Рецепт стекла взят из веб-темы CopBot «Liquid Glass» и приглушён: карточки на стекле и
цветную «обойную» подложку референса не берём (брейншторм 2026-10-22).

Цвет банка — данные (`UserBank.colorHex`). Текст на аватаре банка — белый или чёрный по
яркости цвета (`BankAvatar` считает сам). Жёлтые банки (Т-Банк, Райффайзен) получают
чёрную букву.
