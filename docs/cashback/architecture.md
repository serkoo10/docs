# Архитектура

## Что это

Приложение-справочник: пользователь ведёт список своих банков и то, какие категории
кэшбэка он включил в каждом банке на текущий месяц. Главный экран отвечает на вопрос
«чем платить за такси / продукты / АЗС сейчас». Источник данных один — сам пользователь:
руками или через распознавание скриншота экрана банка.

Серверной части нет. Все данные — один JSON-документ на устройстве. Единственный
внешний вызов — Claude API для распознавания скриншота, ключ пользователя лежит в Keychain.

## Клиент

```

  app.dart                  MaterialApp.router, тема, локализация
  app/app_router.dart       go_router, сборка маршрутов фич
  core/
    catalog/                справочник банков (asset banks.json) и категории
    models/                 YearMonth, UserBank, Offer, OfferSet, AppStore (freezed)
    store/                  StoreFile (чтение/запись JSON), AppStoreNotifier — владелец документа
    recognition/            RecognitionApi (dio → api.anthropic.com), схема ответа, подбор банка
    settings/               AppSettings (тема, напоминание) в shared_preferences, ApiKeyStorage
    reminder/               планировщик ежемесячного напоминания
    router/                 AppRoutes, HomeTab
    theme/                  палитра, токены, ThemeData
  features/
    home/                   три вкладки: Сейчас, Банки, Настройки
    best/                   вкладка «Сейчас»: лучшие ставки по категориям
    banks/                  список банков, экран банка, добавление банка, редактор категории
    import/                 импорт скриншота: машина состояний распознавания и проверки
    settings/               вкладка настроек, экран ключа
  shared/
    domain/                 форматирование процентов и месяцев
    presentation/           AsyncBody, EmptyState, ConfirmDialog, BankAvatar, CategoryIcon, …

```

Слои внутри фичи — как в runclub: `data` (нотификаторы, команды), `domain` (чистые
правила), `presentation` (экраны и виджеты). Фича не импортирует другую фичу; общее
уходит в `core` или `shared`.

## Модель данных

```
YearMonth        год + месяц; ключ "2026-10"; prev/next; fromDate
CashbackCategory enum из 28 значений; у каждого hint для модели распознавания
UserBank         id, name, colorHex, catalogId?, shortcutName?, addedAt
Offer            category, percent, merchant?, limitRub?
OfferSet         bankId, period, offers, source (manual | screenshot), updatedAt
AppStore         banks: [UserBank], offerSets: {"<bankId>/<yyyy-MM>": OfferSet}
```

Решения:

- Банк из каталога и «свой банк» — одна сущность. При добавлении из каталога имя и
  цвет копируются в `UserBank`, `catalogId` хранится для сопоставления при распознавании.
  Дальше никто не различает их по происхождению.
- Приложение банка открывается через «Команду» iOS (`shortcuts://run-shortcut?name=`),
  имя хранится в `UserBank.shortcutName`: у приложений банков нет стабильных URL-схем.
  Поле принадлежит пользователю, в каталоге его нет.
- Период — календарный месяц. Банки с квартальными категориями ведутся по месяцам, для
  этого есть «повторить прошлый месяц».
- Категории нормализованы в enum, иначе «Кафе и рестораны» одного банка и «Рестораны»
  другого не сравнить. Нестандартные попадают в `other` с названием в `merchant`.
- Набор категорий банка на месяц хранится целиком и заменяется целиком: импорт
  скриншота перезаписывает месяц, а не сливается с ним. Скриншот — снимок истины.

## Хранилище

`appStoreProvider` (`AsyncNotifierProvider<AppStoreNotifier, AppStore>`) — единственный
владелец документа. Он читает файл при старте, а каждое изменение делает через
`commit(AppStore Function(AppStore))`: новое состояние выставляется сразу, запись файла идёт
следом. Документ маленький (десятки банков × десятки категорий), поэтому пишется целиком
без отложенной записи.

Фичи не держат своих копий: `banksProvider`, `offerSetProvider((bankId, period))`,
`bestOffersProvider(period)` — производные от `appStoreProvider`. Команды (`BankCommands`,
`OfferCommands`) — тонкие обёртки над `update`.

Файл: `<ApplicationSupport>/store.json`, версия схемы в поле `version` для будущих миграций.

## Лучшие ставки

`bestOffers(store, period)` — один проход по банкам пользователя: для каждого берётся
набор по ключу `"<bankId>/<period>"`, его предложения раскладываются в
`Map<CashbackCategory, List<BankOffer>>`; списки сортируются по проценту. Категория `all`
(«на всё») попадает в сводку отдельной строкой и не раскладывается по остальным.

## Распознавание скриншота

Поток в `features/import` — явная машина состояний (`ImportState`, sealed):

```
idle ──pick──▶ recognizing(image) ──ok──▶ review(draft) ──save──▶ saving ──▶ done
                      │                        ▲
                      └──error──▶ failed(error, image) ──retry──┘
```

- `recognizing`: картинка уходит в `RecognitionApi.recognize(bytes)`.
- `review`: черновик — выбранный банк (подобран по названию через псевдонимы каталога,
  пользователь может сменить), месяц, список предложений; каждую строку можно править или
  удалить, перед сохранением всё видно.
- `saving`: набор месяца заменяется черновиком, источник `screenshot`.

По умолчанию распознавание локальное (`LocalRecognitionApi`, `core/recognition/local`): Apple Vision
читает строки с рамками (`TextRecognizer`), `parseScreenshot` собирает из них предложения по
алиасам категорий, банк подбирается по каталогу; результат открывается в `review`.

Запасной путь, в интерфейсе скрыт (код и ключ в Keychain остаются): `ClaudeRecognitionApi` —
`POST https://api.anthropic.com/v1/messages`, модель `claude-opus-5-5`,
без стриминга (ответ короткий), `output_config.format` с JSON-схемой — ответ всегда валидный
JSON нужной формы, `fallbacks: "default"` с заголовком `server-side-fallback-2026-07-01`.
Усилие `low`: извлечению со скриншота размышление не нужно, а его токены тоже входят в
`max_tokens`. Ответ со `stop_reason: refusal` — ошибка `RecognitionException.refused`,
`max_tokens` → `truncated` (JSON неполный, разбирать нечего). 401 →
`invalidKey`, 429 → `rateLimited`, сеть → `network`, остальное → `server`.

Картинка перед отправкой уменьшается до 1600 px по длинной стороне и сжимается в JPEG
(`image_picker` делает это сам при выборе): скриншот банка читается и так, а токенов
в несколько раз меньше.

## Напоминание

Раз в месяц локальное уведомление «Обновите категории кэшбэка» в выбранный день в 10:00.
`flutter_local_notifications` + `timezone`; часовой пояс берётся с устройства. Разрешение
на уведомления запрашивается при включении тумблера, не на старте.

## Что откладываем сознательно

- Share Extension (поделиться скриншотом из Фото прямо в приложение): нужен отдельный
  таргет в Xcode; пока скриншот выбирается из галереи кнопкой.
- Синхронизация между устройствами и бэкап: нет сервера; экспорт JSON — кандидат на
  следующий шаг.
- Учёт лимитов и уже заработанного кэшбэка: приложение показывает ставки, не считает деньги.
- Android: все пакеты кроссплатформенные, но проект создан только с iOS.
