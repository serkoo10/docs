# Документация

Документация по проектам. Сайт — источник истины: если код и страница здесь расходятся,
одно из них ошибка.

Страницы собираются из `README.md` и `docs/` каждого проекта командой `pnpm sync`;
список проектов и их пути лежат в `projects.json`. У каждого проекта своя папка.
План проекта живёт в `docs/plan.md`, задачи из него превращаются в GitHub Issues
командой `pnpm tasks <проект>`.

## Проекты

- [runclub](./runclub/index.md) — беговое приложение для тренеров и бегунов: клубы, тренировки, достижения, забеги, кроссовки.
- [cashback](./cashback/index.md) — личный агрегатор кэшбэка по банкам РФ (Flutter, iOS).
- [studcore](./studcore/index.md) — учёт контингента и документов для вузов (Go).
- [airdrop-agent](./airdrop-agent/index.md) — Telegram-юзербот, который ищет airdrop-возможности в крипто-чатах через Claude.
- [bg-advisor](./bg-advisor/index.md) — советник по партиям в нарды.
